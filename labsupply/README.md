# LabSupply – ระบบเบิกของเข้าวอร์ด

ต้นแบบระบบเบิกวัสดุของ Sakaeo Rajanagarindra Psychiatric hospital เขียนด้วย HTML / CSS / JavaScript ล้วน ใช้งานบน GitHub Pages ได้ทันที

## โครงสร้างโฟลเดอร์ (ต้องรักษาไว้ตามนี้)
```
index.html  style.css  app.js  README.md   ← หน้าเข้าสู่ระบบ (หน้าเดียวของทุกบัญชี)
shared.js                                  ← ส่วนกลาง: บัญชี/ล็อกอิน, ช่องเซ็นลายมือ, ฟอร์ม PDF
user/   index.html style.css app.js README.md   ← หน้าบ้าน (ผู้ใช้ขอเบิก)
admin/  index.html style.css app.js README.md   ← หลังบ้าน (ผู้ดูแลระบบ)
```
ไฟล์ชื่อซ้ำกันในแต่ละโฟลเดอร์ ห้ามนำมารวมในโฟลเดอร์เดียว ให้ใช้ไฟล์ `labsupply.zip` แตกแล้วอัปโหลดทั้งโฟลเดอร์

## การเข้าสู่ระบบ
- เปิด `index.html` ที่โฟลเดอร์หลัก (https://\<user\>.github.io/\<repo\>/) ทุกคนล็อกอินที่หน้านี้หน้าเดียว
- **ผู้ดูแลระบบ** → พาไปหลังบ้าน (`admin/`) · **ผู้ใช้** → พาไปหน้าบ้าน (`user/`)
- บัญชีผู้ดูแลระบบเริ่มต้น: ชื่อผู้ใช้ `lab1234` รหัสผ่าน `1234` (เปลี่ยนรหัสผ่านที่เมนู "บัญชี" ของหลังบ้านได้)
- บัญชีผู้ใช้สร้าง/แก้ไข/ลบ/รีเซ็ตรหัสผ่านได้ที่หลังบ้าน เมนู "บัญชี"
- เปิดหน้าผิดฝั่งหรือยังไม่ล็อกอิน ระบบพากลับไปหน้าที่ถูกต้องอัตโนมัติ

## วิธีขึ้น GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดตามโครงสร้างด้านบน
2. Settings → Pages → Branch: `main` / root → Save
3. เข้า `https://<user>.github.io/<repo>/`

## ระบบสต็อก (1 ชิ้น = 1 บาร์โค้ด)
- เมนู **สต็อก** มี 2 ปุ่ม: **รายการพัสดุ** และ **เพิ่มรายการ**
- แต่ละพัสดุมี 4 ปุ่ม: **พิมพ์** (พิมพ์บาร์โค้ดทั้งหมดหรือเฉพาะ Lot) · **แก้ไข** (ชื่อ หน่วยนับ ตำแหน่ง และแต่ละล็อต: เลข Lot, วันที่เพิ่ม, วันหมดอายุ, ราคา, จำนวน) · **ลบ** (ลบรายการ) · **รายละเอียด** (ดูบาร์โค้ดทุกชิ้น)
- หน้าเพิ่มรายการกรอก **เลข Lot** และ **ราคาต่อหน่วย** ได้ และ **พิมพ์หน่วยนับเองได้** (เลือกจากรายการหรือพิมพ์ใหม่)
- แก้ไขจำนวนในล็อต: เพิ่ม = สร้างบาร์โค้ดใหม่ให้ชิ้นที่เพิ่ม (ต้องพิมพ์ไปติด) · ลด = ตัดจำหน่ายชิ้นท้ายล็อตที่ยังไม่จ่าย
- ลบรายการ = ซ่อนรายการ ตัดจำหน่ายชิ้นที่ยังเหลือ แต่เก็บประวัติการจ่ายไว้เพื่อสืบย้อนหลัง
- นำเข้า 20 กล่อง = สร้างบาร์โค้ด 20 ดวง (รหัส `LS` + เลข 8 หลักรันต่อเนื่อง ไม่ซ้ำ) แล้วสั่งพิมพ์สติกเกอร์ไปติดแต่ละกล่อง
- ดูรายละเอียดของพัสดุจะเห็นทุกชิ้น: บาร์โค้ด วันที่นำเข้า วันหมดอายุ และถ้าจ่ายแล้วจะบอกว่าจ่ายให้ใคร Ward ไหน ใบเบิกใด ใครเป็นผู้จ่าย/ผู้รับ
- ชิ้นที่หมดอายุไม่นับในคงเหลือ และลบได้ (ระบบเก็บเป็นประวัติ "ตัดจำหน่าย" ไม่ลบทิ้งจริง)
- ตอนจัดของต้องสแกนบาร์โค้ดของชิ้นที่หยิบจริงให้ครบจำนวน ชิ้นหมดอายุหรือถูกจ่ายไปแล้วจะสแกนไม่ผ่าน ปุ่ม "เลือกอัตโนมัติ" ใช้ชิ้นที่ใกล้หมดอายุก่อน

### บาร์โค้ด: ไฟล์ Word กระดาษ 55.1 × 26.0 มม. (ตรงกับสต็อก USER ของ Xprinter XP-350B) ระยะขอบ 0.3 ซม. (1 หน้า = 1 บาร์โค้ด)
- กด **ดาวน์โหลดไฟล์ Word** (หลังนำเข้า หรือที่ปุ่ม "พิมพ์" ของพัสดุแต่ละรายการ) ได้ไฟล์ .docx ที่ขนาดกระดาษ 55.1 × 26.0 มม. ระยะขอบ 0.3 ซม. ทุกด้าน (ตั้งใน Word: กระดาษแบบกำหนดเอง, แหล่งกระดาษ = ม้วนต่อเนื่อง) แต่ละหน้ามี 1 บาร์โค้ด พร้อมชื่อพัสดุ เลข Lot วันนำเข้า และวันหมดอายุ
- บาร์โค้ดรันเลขต่อเนื่องตามจำนวนของ เช่น นำเข้า 20 กล่อง = LS00000001–LS00000020 = 20 หน้า
- ปุ่ม "พิมพ์" เลือกได้ว่าจะพิมพ์ทั้งหมดที่ยังอยู่ในสต็อก หรือเฉพาะ Lot ใด Lot หนึ่ง
- ตั้งค่าการพิมพ์ใน Word: ใช้ขนาดกระดาษของไฟล์ กระดาษ 55.1 × 26.0 มม. (ตรงกับสต็อก USER ของ Xprinter XP-350B) ระยะขอบ 0.3 ซม. ขนาดจริง 100% ไม่ย่อให้พอดี
- ไฟล์นี้ไม่ได้ผูกกับฟังก์ชัน "จดหมายเวียน" (Mail Merge) ของ Word เปิดแล้วสั่งพิมพ์ได้ทันที
- ยังมีตัวเลือกพิมพ์ตรงผ่านหน้าต่างพิมพ์ไปที่ Xprinter (ขนาดเริ่มต้น 55.1 × 26 มม. ขอบ 3 มม. ปรับได้) ยังไม่ได้ส่งคำสั่งตรงเข้าเครื่องพิมพ์ผ่าน USB/Bluetooth

## เมนูบัญชี (ปุ่มไอคอน) และชื่อหน่วยงาน (Ward)
เมนู **บัญชี** แสดงเป็นปุ่มไอคอนขนาดใหญ่: บัญชีของฉัน / ผู้ใช้งาน / หน่วยงาน / ออกจากระบบ (ผู้ดูแลระบบเห็นครบ) กดแล้วจึงเข้าหน้ารายละเอียด
- **หน่วยงาน**: เพิ่ม แก้ไขชื่อ ลบ ได้ การแก้ชื่อจะเปลี่ยนในบัญชีผู้ใช้และใบเบิกเดิมให้ตรงกันด้วย ลบไม่ได้ถ้ายังมีบัญชีใช้ Ward นั้นอยู่

## ประวัติการนำออก
- แยกเป็นกลุ่มตามเดือน/ปี เดือนล่าสุดอยู่บนสุด ในเดือนเรียงจากวันที่ล่าสุดก่อน หัวข้อของแต่ละใบเบิกคือ วันเดือนปี · หน่วยงาน
- แต่ละเดือนมีปุ่ม **ดาวน์โหลดฟอร์มใบเบิกทั้งเดือน** รวมทุกฟอร์มเป็น PDF ไฟล์เดียว (ตามตัวกรองที่เลือกอยู่) และมีปุ่มดาวน์โหลด Excel ของรายการที่กรอง
- ถ้าโหลดไลบรารี PDF ไม่ได้ ระบบเปิดหน้าต่างพิมพ์รวมทุกฟอร์มให้เลือก "บันทึกเป็น PDF" แทน

## ขั้นตอนการเบิกและจ่ายของ
1. ผู้ใช้ส่งคำขอเบิก (3 ขั้นตอน) → เข้าคิวหลังบ้านและมีแจ้งเตือน
2. ผู้ดูแลตรวจ/แก้ไข → สแกนบาร์โค้ดทีละชิ้น → ตัดสต็อก → สถานะ "พร้อมรับของแล้ว"
3. ผู้ขอเบิก/ผู้รับมารับของ แล้วกรอกชื่อ **และเซ็นลายมือ** ที่หน้าบ้าน → "เซ็นรับของ"
4. หลังผู้รับเซ็นแล้ว แอดมินจึง **เลือกชื่อผู้จ่ายและเซ็นยืนยัน** ที่หลังบ้าน → "ยืนยันการจ่ายของ" → ใบเบิกล็อกถาวร (ก่อนผู้รับเซ็น แอดมินยังเลือกชื่อ/เซ็นจ่ายไม่ได้)
5. ดาวน์โหลดฟอร์มใบเบิก (PDF) พร้อมลายเซ็นสองฝ่ายได้ที่หน้าบ้าน (หลังแอดมินยืนยันจ่าย) และหลังบ้าน (ประวัติ)

## ข้อจำกัดของเวอร์ชันนี้ (สำคัญ)
- **ระบบล็อกอินเป็นแบบต้นแบบ ไม่ปลอดภัยพอสำหรับข้อมูลจริง** รหัสผ่านเข้ารหัส (PBKDF2) แต่เก็บใน `localStorage` ของเบราว์เซอร์ ใครเข้าถึงเครื่องหรือเปิด DevTools ก็แก้ข้อมูลได้ รหัสผ่านเริ่มต้นสั้น (`1234`) ควรเปลี่ยนก่อนใช้งานจริง
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องเดียว บัญชีที่สร้างในเครื่องหนึ่งจะไม่มีในอีกเครื่อง
- เวลาที่บันทึกมาจากเครื่องผู้ใช้ ยังไม่ใช่เวลาจากเซิร์ฟเวอร์
- วันหมดอายุเทียบกับวันที่ในเครื่องที่เปิดใช้งาน
- สต็อกเดิมแบบนับจำนวนจะถูกแปลงเป็นรายชิ้นอัตโนมัติครั้งเดียว (ไม่มีวันหมดอายุ) และต้องพิมพ์บาร์โค้ดไปติดของที่มีอยู่จริง (ปุ่ม "พิมพ์บาร์โค้ดที่ยังอยู่ในสต็อกทั้งหมด")
- ขั้นต่อไปสำหรับใช้งานจริง: ต่อ backend (Firebase / Supabase) เพื่อยืนยันตัวตน เก็บข้อมูลร่วมกัน ประทับเวลาจากเซิร์ฟเวอร์ และส่ง Push

### เลือกหลายชิ้น / แยกตาม Lot (เมนูสต็อก → รายละเอียด)
- รายละเอียดพัสดุแสดงแยกเป็นกลุ่มตาม **Lot** แต่ละกลุ่มมีช่องติ๊กเลือกทั้ง Lot, ปุ่ม **พิมพ์ทั้ง Lot (Word)**, **พิมพ์ Xprinter** และ **ลบทั้ง Lot**
- แต่ละชิ้นที่ยังอยู่ในสต็อกมีช่องติ๊ก เลือกได้ทีละชิ้นหรือหลายชิ้น หรือ "เลือกทั้งหมด"
- แถบด้านบน: **พิมพ์ที่เลือก (Word)** · **พิมพ์ Xprinter** · **นำที่เลือกออกจากสต็อก** (กรอกเหตุผลได้ ระบบเก็บเป็นประวัติ "ตัดจำหน่าย") · ล้างที่เลือก

### ตั้งค่าพิมพ์สติกเกอร์ที่ Xprinter XP-350B (สต็อก USER 55.1 × 26.0 มม.)
- ไดรเวอร์: แนวการพิมพ์ = **แนวตั้ง** · ไฟล์ Word สร้างมาเป็นหน้ากว้าง 55.1 × สูง 26.0 มม. โดยกำหนดแนวหน้าเป็น "แนวตั้ง" (ไม่ใช่แนวนอน) เพื่อไม่ให้ไดรเวอร์หมุนหน้าซ้ำ
- ถ้าตั้งค่าหน้าใน Word เอง: เลือกแนวตั้งก่อน แล้วค่อยกรอกกว้าง 5.51 × สูง 2.6 ซม. (ถ้าเลือกแนวนอน ไดรเวอร์จะหมุนข้อมูลจนล้นไปอีกดวง)
- ปุ่ม **พิมพ์ Xprinter** (พิมพ์ตรงจากเบราว์เซอร์) ใช้ค่าเดียวกัน: ฉลาก 55.1 × 26.0 มม. เว้นขอบ 0.3 ซม. ทุกด้าน ชื่อพัสดุ 1 บรรทัด (ยาวเกินตัดด้วย …) · ในหน้าต่างพิมพ์เลือกกระดาษ USER, แนวตั้ง, Margins = ไม่มี, สเกล 100%, ปิดหัว-ท้ายกระดาษ

## อัปเดต: แผนก / เบิกแบบติ๊กเลือก / แอดมินเบิกเอง / Excel
- **Ward ล็อกตามบัญชี**: หน้าเบิกของผู้ใช้ใช้ Ward ที่ผูกกับบัญชีที่ล็อกอิน (กำหนดที่ บัญชี › ผู้ใช้งาน) · **ชื่อ-นามสกุลผู้ขอเบิกแก้ไขได้** (ค่าเริ่มต้นคือชื่อบัญชี) เพื่อใส่ชื่อจริงของผู้เบิก
- **เลือกรายการเบิก**: ติ๊กเลือก + ปุ่ม +/− จำนวน (หน่วยนับตามที่แอดมินตั้ง) แยกตามแผนกอัตโนมัติ · กด 📌 ปักรายการเบิกประจำไว้บนสุด (เก็บแยกตามบัญชี)
- **แอดมินเบิกเอง**: เลือกชื่อแอดมิน + Ward + ติ๊กรายการ → ถัดไป → สรุปและยืนยัน (ไม่ต้องกรอกผู้จ่าย/ผู้รับ ไม่ต้องเซ็นรับ)
- **ผู้จ่าย / แอดมินหลายคนใช้ล็อกอินเดียวกัน**: บัญชี › ผู้จ่าย / ลายเซ็น เพิ่มชื่อและลายเซ็นของแต่ละคน · เลือกชื่อตอนยืนยันจ่ายของหรือเบิกเอง ลายเซ็นขึ้นอัตโนมัติ (ชื่อที่เลือกล่าสุดจะถูกจำไว้)
- **ประวัติ**: ดาวน์โหลด Excel รายเดือน (วันที่นำออก, บาร์โค้ด, นำออก/ทั้งหมดของ Lot, รายการ, Lot, วันหมดอายุ, หน่วยงาน) และรายปี (แผนก, รายการ, ราคา, หน่วยนับ, คงเหลือรวม, วันหมดอายุ, Lot, คงเหลือใน Lot)
- **สต็อก**: เหลือเฉพาะปุ่มพิมพ์ (ไม่มีปุ่ม Word) · รายการแสดงเป็นตารางแยกแผนก มี Lot/คงเหลือ/วันหมดอายุ · แท็บ "ตั้งค่า" เพิ่ม/แก้/ลบแผนกและย้ายรายการเข้าแผนก · เพิ่มรายการต้องเลือกแผนกก่อน

## หน้ารายการพัสดุ (ตาราง)
- แสดงเป็นตาราง: แผนก · ประเภท · ชื่อสินค้า · Note (Config) · หน่วยนับ · จำนวนรวม · เหลือ (ไม่หมดอายุ) · วันหมดอายุ (เหลือกี่วัน) · Lot · จำนวน (Lot) · สถานะ · จัดการ — สินค้าที่มีหลาย Lot จะแตกเป็นหลายแถว (เรียงตามวันหมดอายุ) และหัวตารางค้างอยู่เวลาเลื่อน
- เรียงตามแผนก → ประเภท → ชื่อสินค้า ข้อความ "แสดงสินค้าในสต็อก: N รายการ" นับตามตัวกรอง
- ตัวกรอง: แผนก, ประเภท, Exp Alarm (หมดอายุแล้ว/ใกล้หมดอายุภายใน N วัน), Min Alert (ต่ำกว่าจำนวนขั้นต่ำ), ค้นหาชื่อสินค้า/Lot และปุ่ม รีเฟรช / ล้าง Filter / Export Excel (ตามตัวกรอง)
- คลิกแถวเพื่อไฮไลต์ ปุ่มในคอลัมน์ "จัดการ": พิมพ์บาร์โค้ด · แก้ไข · ลบรายการ · รายละเอียดรายชิ้น
- สถานะ: ปกติ / ใกล้หมดอายุ / มีของหมดอายุ / ต่ำกว่าขั้นต่ำ (สินค้าที่หมดสต็อกแต่ไม่ได้ตั้งขั้นต่ำถือว่า "ปกติ")

## ฟอร์มใบเบิก (PDF) 2 แบบ
- **Ward ขอเบิก**: ผู้ขอเบิก · Ward · ผู้จ่ายของ (ลายเซ็น) · ผู้รับของ (ลายเซ็น)
- **แอดมินเบิกเอง**: หัวฟอร์ม "ใบเบิกวัสดุ (แอดมินเบิกเอง)" · ผู้เบิก · Ward · ลายเซ็นผู้เบิกเพียงช่องเดียว (ไม่มีผู้จ่าย/ผู้รับ)
- ดาวน์โหลดรวมทั้งเดือนได้ตามปกติ ทั้งสองแบบอยู่ในไฟล์ PDF เดียวกัน

## อัปเดต: ประวัตินำออกจากสต็อก / ราคา / แจ้งเตือน / ประเภท
- **ประวัติ** แสดงทั้งการเบิก และการ **นำออกจากสต็อกที่ไม่ใช่การเบิก** (สินค้ามีปัญหา/ไม่ใช้แล้ว, หมดอายุ, ปรับลดจำนวน, ลบรายการ หรือเหตุผลอื่นที่ระบุเอง) เรียงรวมตามเดือน แสดงสินค้า จำนวน เหตุผล ผู้นำออก Lot และบาร์โค้ด · เลือกแสดง "ทั้งหมด / เฉพาะการเบิก / เฉพาะนำออกจากสต็อก" ได้ · Excel มีชีต "นำออกจากสต็อก" เพิ่ม
- **ตารางรายการพัสดุ**: เอาคอลัมน์ Note (Config) ออก แสดง **ราคา/หน่วย** ของแต่ละ Lot แทน
- **แจ้งเตือน (กระดิ่ง 🔔)**: มีตัวเลขบนกระดิ่ง กดดูรายการ หมดอายุแล้ว / ใกล้หมดอายุ / จำนวนใกล้หมด และเด้งแจ้งเตือนวันละครั้งเมื่อเปิดระบบ
- **ตั้งค่าแจ้งเตือนรายการละค่า** ตอนเพิ่มรายการใหม่ (และแก้ไขภายหลังได้): "แจ้งเตือนเมื่อเหลือไม่เกิน (จำนวน)" และ "แจ้งเตือนก่อนหมดอายุ (วัน)" ค่าเริ่มต้น 30 วัน · ใส่ 0 = ไม่แจ้ง · ตัวกรอง Exp Alarm / Min Alert ใช้ค่าของแต่ละรายการ
- **ประเภท**: เลือกจากรายการ (ไม่ต้องพิมพ์) · เพิ่ม/แก้ไข/ลบที่ สต็อก › ตั้งค่า › ประเภท (แก้ชื่อแล้วเปลี่ยนในทุกรายการ, ลบไม่ได้ถ้ายังมีรายการใช้อยู่)
