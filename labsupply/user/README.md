# LabSupply – หน้าบ้าน (ผู้ใช้ขอเบิก)

เข้าใช้งานผ่านหน้าเข้าสู่ระบบที่โฟลเดอร์หลัก ไม่ต้องเปิดโฟลเดอร์นี้โดยตรง (ถ้ายังไม่ล็อกอินระบบจะพากลับไปหน้าล็อกอิน)

- Ward ของผู้ขอเบิกมาจากบัญชีที่ล็อกอิน แก้ไม่ได้ · ชื่อ-นามสกุลผู้ขอเบิกแก้ไขได้ (ค่าเริ่มต้นคือชื่อบัญชี)
- ผู้ใช้เห็นเฉพาะใบเบิกของตัวเอง
- เบิกของ 3 ขั้นตอน → ติดตามสถานะ → เซ็นรับของ (กรอกชื่อผู้รับและเซ็นลายมือ) → รอแอดมินเลือกชื่อและเซ็นยืนยันการจ่าย → ดาวน์โหลดฟอร์ม PDF
- เมนูชื่อมุมบนขวา: เปลี่ยนรหัสผ่าน / ออกจากระบบ
- ต้องมี `../shared.js` ตามโครงสร้างโฟลเดอร์ใน README หลัก
- รายการพัสดุที่เลือกเบิกอ่านจากสต็อกหลังบ้าน แสดงเฉพาะที่ยังมีของใช้ได้ และเบิกเกินจำนวนคงเหลือไม่ได้
- รายชื่อ Ward ตามที่ผู้ดูแลระบบตั้งไว้
