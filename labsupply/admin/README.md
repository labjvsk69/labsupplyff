# LabSupply – ระบบหลังบ้าน (เจ้าหน้าที่สโตร์)

ระบบหลังบ้านแยกจากหน้าบ้าน อยู่ในโฟลเดอร์ `admin/` เปิดใช้งานบนมือถือเป็นหลัก

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ (โหลด SheetJS, html2canvas, jsPDF จาก cdnjs และ `../shared.js`) |
| `style.css` | สไตล์ (ใช้ชุดเดียวกับหน้าบ้าน + ส่วนของหลังบ้าน) |
| `app.js` | ตรรกะทั้งหมดของหลังบ้าน |
| `README.md` | ไฟล์นี้ |

## โครงสร้างบน repo
ดูไฟล์ README.md ที่โฟลเดอร์หลัก (หน้าล็อกอิน `index.html` + `user/` + `admin/` + `shared.js`)

## ฟีเจอร์ (ตรงกับที่ระบุ)
1. **คิวใบเบิก + แก้ไข** ดูใบเบิกจากหน้าบ้าน ค้นหา/กรอง แก้ชื่อ Ward เวลา และรายการสินค้าได้ก่อนตัดสต็อก ต้องใส่เหตุผลทุกครั้ง ระบบเก็บค่าก่อนแก้ไว้ใน `edits`
2. **สแกนบาร์โค้ด → ตัดสต็อก** ใช้กล้องมือถือสแกน (ต้อง HTTPS และเบราว์เซอร์ที่รองรับ BarcodeDetector เช่น Chrome บน Android) หรือกรอกรหัสด้วยมือ สแกนครบแล้วไปหน้าตัดสต็อก ระบบลดจำนวนในสต็อกและบันทึกความเคลื่อนไหว
3. **แจ้งสถานะ + ยืนยันจ่ายของ** ตัดสต็อกแล้วสถานะหน้าบ้านเปลี่ยนเป็น "พร้อมรับของแล้ว" ทันที หลังผู้รับเซ็นรับของที่หน้าบ้านแล้ว เจ้าหน้าที่เลือกชื่อผู้จ่ายและเซ็นยืนยัน ระบบบันทึกเวลาอัตโนมัติและล็อกใบเบิก
4. **ประวัติการนำออก + Excel** กรองตามวันที่ Ward ผู้จ่ายของ และดาวน์โหลด .xlsx (หนึ่งแถวต่อสินค้าหนึ่งรายการ) ถ้าโหลดไลบรารีไม่ได้จะดาวน์โหลดเป็น .csv แทน
5. **แจ้งเตือนใบเบิกใหม่** แถบแจ้งเตือน + เสียง + สั่น และ Notification ของเบราว์เซอร์ (กดไอคอนกระดิ่งเพื่ออนุญาต)
6. **เบิกเอง (แอดมิน)** ปุ่มในหน้าคิวใบเบิก ตัดสต็อกทันที ไม่มีแจ้งเตือนและไม่มีสถานะจัดส่ง แต่บันทึกหลักฐานไว้ในประวัติ (ติดป้าย "แอดมินเบิกเอง") และไม่ปรากฏในหน้าบ้าน

นอกจากนี้มีหน้า **สต็อก** สำหรับดูคงเหลือ ปรับยอด/รับเข้า และตั้งบาร์โค้ดของสินค้าแต่ละรายการ

## ข้อจำกัดของเวอร์ชันนี้
- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์ หน้าบ้านและหลังบ้านเห็นข้อมูลร่วมกันได้เฉพาะ**เบราว์เซอร์เดียวกันในเครื่องเดียวกัน** (โดเมนเดียวกัน) ยังใช้ข้ามเครื่องจริงไม่ได้
- เวลาที่บันทึกยังมาจากเครื่องผู้ใช้ ไม่ใช่เซิร์ฟเวอร์
- การแจ้งเตือนเด้งได้เฉพาะตอนเปิดหน้าหลังบ้านค้างไว้ ถ้าจะให้เด้งเข้ามือถือแม้ปิดแอป ต้องใช้ Web Push ร่วมกับ backend
- หน้าบ้านยังใช้รายการสินค้าชุดคงที่ ยังไม่ดึงจากสต็อกของหลังบ้าน

## ขั้นต่อไป
ต่อ backend ร่วมกัน (Firebase / Supabase) โดยแทนที่ก้อน `store` ใน `app.js` ของทั้งสองฝั่ง เพื่อให้ข้อมูลใช้ข้ามเครื่องได้ เวลามาจากเซิร์ฟเวอร์ และส่ง Web Push จริง

## ขั้นตอนจ่ายของ (ยืนยัน 2 ฝ่าย)
1. แอดมินตัดสต็อก → สถานะ "พร้อมรับของแล้ว"
2. ผู้ขอเบิก/ผู้รับมารับของ แล้วกด **เซ็นรับของ** พร้อมลงชื่อที่หน้าบ้านก่อน (แอดมินยังเลือกชื่อ/เซ็นจ่ายไม่ได้จนกว่าผู้รับจะเซ็น)
3. หลังผู้รับเซ็นแล้ว แอดมิน **เลือกชื่อผู้จ่ายและเซ็นยืนยัน** แล้วกด **ยืนยันการจ่ายของ** → ระบบบันทึกเวลาจ่าย ใบเบิกเปลี่ยนเป็น "จ่ายของเรียบร้อย" และล็อกถาวร
หลักฐานเก็บทั้งผู้จ่าย เวลาจ่าย ผู้รับ และเวลารับ ส่วนการเบิกเองของแอดมินไม่มีขั้นตอนรับของ

## เข้าสู่ระบบและจัดการบัญชี
- ล็อกอินที่หน้าเข้าสู่ระบบหน้าเดียวของโฟลเดอร์หลัก บัญชีผู้ดูแลระบบเริ่มต้น `lab1234` / `1234`
- เมนู "บัญชี": **เพิ่ม แก้ไข (ชื่อ ชื่อผู้ใช้ บทบาท Ward) รีเซ็ตรหัสผ่าน เปิด/ปิดใช้งาน และลบ** บัญชีผู้ใช้
- บทบาท: "ผู้ดูแลระบบ" เข้าหลังบ้าน · "ผู้ใช้" เข้าหน้าบ้าน (ต้องระบุ Ward)
- ป้องกันการลบ ปิด หรือลดบทบาทผู้ดูแลระบบคนสุดท้าย และไม่ให้เปลี่ยนบทบาท/ลบ/ปิดบัญชีที่กำลังใช้งานอยู่
- เลือกได้ว่าจะให้ผู้ใช้ตั้งรหัสผ่านใหม่เมื่อเข้าครั้งแรกหรือไม่ · รหัสผ่านอย่างน้อย 4 ตัวอักษร
- ใส่รหัสผ่านผิด 5 ครั้งจะถูกล็อก 1 นาที · เซสชันหมดอายุใน 8 ชั่วโมง

## ลายเซ็นและฟอร์มใบเบิก
- ผู้จ่ายของต้องเลือกชื่อและเซ็นลายมือทุกครั้งก่อนกด "ยืนยันการจ่ายของ" และทำได้หลังผู้รับเซ็นรับของแล้วเท่านั้น
- การเบิกเองของแอดมินต้องเซ็นทั้งผู้จ่ายและผู้รับ
- ปุ่ม "ดาวน์โหลดฟอร์มใบเบิก (PDF)" อยู่ในประวัติการนำออก (กดที่ใบเบิกที่รับของแล้ว)

## สต็อกและบาร์โค้ด / ชื่อ Ward
รายละเอียดอยู่ใน README.md ที่โฟลเดอร์หลัก (หัวข้อ "ระบบสต็อก" และ "ชื่อ Ward") สรุป: เมนูสต็อกมี 2 ปุ่ม (รายการพัสดุ / เพิ่มรายการ) 1 ชิ้นต่อ 1 บาร์โค้ด พิมพ์สติกเกอร์ผ่านหน้าต่างพิมพ์ไปที่ Xprinter ได้ และแก้ชื่อ Ward ได้ที่เมนู "บัญชี" ส่วนการเบิกเองของแอดมินระบบจะหยิบชิ้นที่ใกล้หมดอายุก่อนและบันทึกบาร์โค้ดให้อัตโนมัติ

## อัปเดตล่าสุด
- เมนูบัญชีเป็นปุ่มไอคอนใหญ่ (บัญชีของฉัน / ผู้ใช้งาน / หน่วยงาน / ออกจากระบบ)
- ประวัติแยกตามเดือน-ปี หัวข้อใบเบิกเป็นวันที่ · หน่วยงาน และมีปุ่มดาวน์โหลดฟอร์มทั้งเดือนเป็น PDF
- บาร์โค้ดดาวน์โหลดเป็นไฟล์ Word กระดาษ กระดาษ 55.1 × 26.0 มม. (ตรงกับสต็อก USER ของ Xprinter XP-350B) ระยะขอบ 0.3 ซม. (1 หน้า = 1 บาร์โค้ด) รหัสรันต่อเนื่องตามจำนวน
- หน้าสต็อก: พัสดุแต่ละรายการมีปุ่ม พิมพ์ / แก้ไข / ลบ / รายละเอียด และหน้านำเข้ามีช่องเลข Lot, ราคาต่อหน่วย, หน่วยนับพิมพ์เองได้
